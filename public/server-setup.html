The Back Room

Server Setup Guide — Dunbar Interprise

v1.0.0 · Internal Documentation

1 Requirements

Node.js 20+

Download from nodejs.org. Use the LTS version.

pnpm Recommended

Faster installs. Run npm install -g pnpm after Node.

Git Optional

For cloning and pulling updates. git-scm.com

A static file server

serve, nginx, or Caddy. pnpm add -g serve is easiest.

2 Build the App

Clone or copy the project to your server machine, then:

# Install dependencies
pnpm install

# Build for production
pnpm build

# Output is in the /dist folder
✓ built in 3.2s → dist/

3 Serve It Locally

After building, serve the dist/ folder on your local network:

# Install serve globally (one-time)
pnpm add -g serve

# Serve on port 8080, accessible on LAN
serve dist -l 8080

# Anyone on the same WiFi can access via:
http://YOUR_LAN_IP:8080
# e.g. http://192.168.1.42:8080
💡

Find your LAN IP: run ipconfig (Windows) or ifconfig / ip addr (Linux/Mac). Look for the 192.168.x.x or 10.x.x.x address under your WiFi adapter.

4 Auto-start on Boot (Linux)

Create a systemd service so The Back Room starts automatically when the server boots:

# Create service file
sudo nano /etc/systemd/system/backroom.service
[Unit]
Description=The Back Room
After=network.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/path/to/backroom/dist
ExecStart=/usr/local/bin/serve . -l 8080
Restart=always

[Install]
WantedBy=multi-user.target
# Enable and start
sudo systemctl daemon-reload
sudo systemctl enable backroom
sudo systemctl start backroom

# Check status
sudo systemctl status backroom

5 Auto-start on Boot (Windows)

# Option 1: Task Scheduler (GUI)
# Search "Task Scheduler" → Create Basic Task
# Trigger: "At startup"
# Action: Start a program
# Program: C:\Users\YOU\AppData\Roaming\npm\serve.cmd
# Arguments: C:\path\to\backroom\dist -l 8080

# Option 2: PM2 process manager
npm install -g pm2 pm2-windows-startup
cd C:\path\to\backroom\dist
pm2 serve . 8080 --name backroom
pm2 save
pm2-startup install

6 nginx Config (Advanced)

For production use with a domain name or SSL:

server {
    listen 80;
    server_name backroom.local;   # or your domain

    root /path/to/backroom/dist;
    index index.html;

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Cache static assets
    location ~* \.(js|css|png|svg|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
⚠️

All user data is stored in each user's browser localStorage — it does not sync across devices or browsers. For multi-device sync you'd need a real backend.

7 Network Firewall

Open the port in your OS firewall so other devices can reach it:

# Linux (ufw)
sudo ufw allow 8080/tcp

# Windows Firewall (PowerShell, as admin)
New-NetFirewallRule -DisplayName "BackRoom" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow

8 Updating

# Pull latest changes (if using git)
git pull

# Rebuild
pnpm install && pnpm build

# Restart service (Linux)
sudo systemctl restart backroom
